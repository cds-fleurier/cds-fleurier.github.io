# cds-fleurier.github.io

Site racine du compte, qui ne sert qu'à publier `robots.txt` : les moteurs de recherche ne lisent ce fichier
qu'à la racine du domaine. Il exclut les outils de la team 0 to 100 (données de participants), et laisse
indexable la carte d'urgence (`/carte-urgence/`). Ajouter une ligne `Disallow` pour chaque nouvel outil de la team.
